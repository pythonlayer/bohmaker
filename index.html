Shuffle Patterns (SwapWaves) 📖

Pattern Editor Help

What is a pattern?
Each pattern defines HOW the hats swap. The game picks one randomly every shuffle.

First (hat indices)
The starting positions of hats. For 3 hats: 0, 1, 2
(Position 0 has hat 0, position 1 has hat 1, etc.)

Second (target positions)
Where each hat moves to. If you swap positions 0 and 1:
1, 0, 2
(Hat 0 goes to position 1, hat 1 goes to position 0, hat 2 stays)

Style
SwapStraight - Direct swap
ParabolicUp - Arcs upward
ParabolicDown - Arcs downward

MovementCurve
How smooth the animation is. Try: linear, ease_in_out, bounce

Duration & Cooldown
Duration: How long the swap takes (seconds)
Cooldown: Pause after swap before next action (seconds)

ParabolicHeight
Only for ParabolicUp/Down. Height of the arc in pixels. Leave empty for straight swaps.
